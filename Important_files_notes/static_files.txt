| Setting            | Meaning                                                   |
| ------------------ | --------------------------------------------------------- |
| `STATIC_URL`       | **URL used by browser**                                   |
| `STATICFILES_DIRS` | **Where Django looks for static files**                   |
| `STATIC_ROOT`      | **Where Django collects all static files for deployment** |
