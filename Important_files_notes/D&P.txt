| Development                                                    | Production                                            |
| -------------------------------------------------------------- | ----------------------------------------------------- |
| You are building/testing                                       | Real users use the website                            |
| `runserver`                                                    | Production server setup                               |
| Local computer                                                 | Deployment server                                     |
| Debugging is enabled                                           | `DEBUG = False`                                       |
| Django can serve static files                                  | Static files are usually served separately            |
| `STATICFILES_DIRS` is important for finding extra static files | `STATIC_ROOT` is important for collected static files |
| `collectstatic` usually isn't needed                           | `collectstatic` is normally run                       |
